# Пакет для владельца сайта

Кладётся в его репозиторий, чтобы дальше он мог сам.

## Шаблон `CLAUDE.md`

```markdown
# <ИМЯ> — сайт работ

Портфолио: витрина треков с обложками и плеером, страница на каждый трек.
Живой адрес: <АДРЕС>

## Как устроено

- `site.json` — кто ты и как выглядит сайт: имя, подпись, цвет, шрифты, роли, контакты.
- `data.json` — сами работы. Один блок на трек или альбом.
- `artist_genres.json` — какой артист к какому жанру относится.
- Всё остальное (`index.html`, `track/`, `covers/`, `sitemap.xml`) собирается
  скриптом. **Руками не править** — при следующей сборке перезапишется.

## Как поменять

Правишь `data.json` или `site.json`, потом собираешь и заливаешь:

    python3 skill/scripts/portfolio.py --project . build
    python3 skill/scripts/portfolio.py --project . publish --confirm

## Роли

У каждого трека поле `roles`. Возможные значения:
`write` — написал, `prod` — спродюсировал, `mix` — свёл, `master` — мастеринг.
Можно несколько сразу: `"roles": ["write", "prod", "mix"]`.
От первой роли зависит заголовок страницы трека в поиске.

## Чего не делать

- Не править собранный HTML — источник истины `data.json`.
- Не менять имя репозитория: от него зависит адрес сайта.
- Не удалять `.nojekyll` — без него GitHub ломает сборку.
```

## Шаблон `README.md`

```markdown
# Как добавить работу

Нужен Claude Code. Открываешь папку сайта и пишешь обычными словами:

    добавь на сайт https://open.spotify.com/track/XXXX

Или сразу пачку — плейлистом:

    засинкай плейлист https://open.spotify.com/playlist/XXXX

## Как поставить роли

Создай файл `roles.txt`, по строке на трек:

    Журавли — Klava Koka — продакшн, сведение
    Сто шагов назад — Klava Koka — сведение

Потом:

    python3 skill/scripts/portfolio.py --project . roles roles.txt
    python3 skill/scripts/portfolio.py --project . build
    python3 skill/scripts/portfolio.py --project . publish --confirm

Строки, которые не совпали с названиями треков, скрипт напечатает и не тронет.

## Как убрать работу с сайта

В `data.json` у нужного блока поставь `"hidden": true`, потом собери и залей.
```
