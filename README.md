# artkachev.github.io

Сайт работ КАССЫ — Артема Ткачева. Звукорежиссура, продакшн, сонграйтинг.

100 треков, отдельная страница на каждый. Статика, без сборки и зависимостей.

Как менять — в [CLAUDE.md](CLAUDE.md). Коротко:

```bash
python3 skill/scripts/portfolio.py --project . build
python3 skill/scripts/portfolio.py --project . publish --confirm
```

Первым делом стоит проставить роли по трекам — см. раздел «Роли» в CLAUDE.md.
